# Harikrishna Raval — QA Portfolio Website

A responsive static portfolio website with the supplied QA resume PDF.

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a new public repository, for example `harikrishna-qa-portfolio`.
3. Upload all files and folders from this package, preserving the `assets` folder.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The site URL will be shown in the Pages settings and usually resembles `https://YOUR-USERNAME.github.io/harikrishna-qa-portfolio/`.

The resume link on the site points to `assets/Harikrishna_Raval_QA_Resume.pdf`.

## Before sharing
- Review the contact details and resume.
- Add your LinkedIn profile URL if you want it displayed.
- Confirm you are comfortable publishing your phone number and email publicly.
- The site describes API and Selenium work as learning/practice, not professional QA employment.
